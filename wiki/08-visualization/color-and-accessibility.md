# Цвет и доступность в визуализации

## Почему цвет важен

Цвет — не украшение. Цвет **кодирует информацию**. Плохой выбор цвета = искажение восприятия или потеря данных (10% мужчин — дальтоники).

## Типы цветовых схем

### Sequential (последовательная)

Для упорядоченных данных (от меньшего к большему):

```
Светлый ──────────────────→ Тёмный
#f7fbff → #6baed6 → #2171b5 → #08306b
```

Одна цветность (hue), меняется lightness/saturation.

### Diverging (расходящаяся)

Для данных с нейтральной серединой (отклонения, корреляции):

```
Отрицательное ← Нейтральное → Положительное
#d73027 → #f7f7f7 → #4575b4
```

Два контрастных цвета от нейтрального центра.

### Qualitative (качественная)

Для неупорядоченных категорий:

```
Категория A, B, C, D — разные цвета, равная яркость
```

Не больше 8-10 цветов, иначе неразличимы.

## Доступность: дальтонизм

~8% мужчин и ~0.5% женщин имеют нарушения цветовосприятия. Самый частый — дейтеранопия (красный/зелёный).

### Плохие комбинации

- Красный + Зелёный (классический traffic light — неразличим)
- Зелёный + Коричневый
- Синий + Фиолетовый

### Хорошие комбинации

- Синий + Оранжевый (безопасно для всех типов дальтонизма)
- Синий + Красный
- Чёрный + цвет

### Проверка

- [Coolors.co](https://coolors.co) — генератор палитр с симуляцией дальтонизма
- `sns.color_palette('colorblind')` — Seaborn-палитра для дальтоников
- `px.colors.qualitative.Safe` — Plotly-палитра

## Практические правила

### 1. Не кодируй только цветом

Добавь второй канал:
- Цвет + форма маркера (○ vs △)
- Цвет + текстура (сплошной vs штриховка)
- Цвет + подпись

### 2. Учитывай культурный контекст

- Красный = опасность/стоп (Запад) vs удача (Китай)
- Зелёный = хорошо (Запад) vs может иметь разный смысл

### 3. Ограничь палитру

- 4-6 цветов для категорий
- Не включай «радугу» (jet/rainbow colormap) — искажает восприятие величин

### 4. Достаточный контраст

Текст на фоне: contrast ratio ≥ 4.5:1 (WCAG AA). Проверка: [WebAIM Contrast Checker](https://webaim.org/resources/contrastchecker/).

## Готовые палитры

```python
# Seaborn
sns.color_palette('viridis')       # sequential, perceptual uniform
sns.color_palette('coolwarm')      # diverging
sns.color_palette('colorblind')    # qualitative, safe

# Plotly
px.colors.sequential.Viridis
px.colors.diverging.RdBu
px.colors.qualitative.Plotly

# Matplotlib
plt.cm.viridis
plt.cm.coolwarm
plt.cm.Set2
```

### Почему Viridis, а не Jet

Jet (радуга) — стандартная палитра старого matplotlib. Проблемы:
- Не perceptual uniform: равные шаги данных ≠ равные шаги восприятия
- Жёлтый «выпрыгивает» — создаёт ложные паттерны
- Плох для дальтоников и ч/б печати

Viridis — perceptual uniform, безопасен для дальтоников, хорошо выглядит в ч/б.
