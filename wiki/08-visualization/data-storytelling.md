# Сторителлинг данными

## Что это

Сторителлинг — перевод аналитических выводов в **нарратив**, который запоминается и побуждает к действию. Анализ без истории — мёртвый PDF.

## Структура нарратива

### Модель: Setup → Conflict → Resolution

```
Setup:    «Вот как обстояли дела»
Conflict: «Но потом случилось ЭТО»
Resolution: «И вот что мы делаем»
```

### Применительно к аналитике

```
1. Контекст    — как было, почему это важно
2. Инсайт      — что мы нашли (график + ключевое наблюдение)
3. Причина     — почему это произошло (гипотеза, подтверждение)
4. Действие    — что делать дальше (рекомендация)
```

## Принципы хорошей истории

### 1. Один главный вывод на график

Не «вот дашборд, разбирайтесь». А «вот график — смотрите, здесь падение в выходные».

```python
# Плохо: просто график
sns.lineplot(data=df, x='date', y='revenue')

# Хорошо: график + аннотация + вывод
g = sns.lineplot(data=df, x='date', y='revenue')
g.axvline(x='2024-06-01', color='red', linestyle='--')
g.text(x='2024-06-01', y=max_revenue, s='Запуск новой версии')
```

### 2. Контраст привлекает внимание

- Выдели аномалию цветом
- Покажи «до и после»
- Сравни ожидаемое с фактическим

### 3. Простота побеждает

- 1 график с 2 линиями > 3 графика с 10 линиями
- Убери легенду, если линий мало — подпиши прямо на графике
- Используй аннотации вместо текста под графиком

## Форматы сторителлинга

### Executive Summary (на 1 минуту)

- 1-2 графика
- 3 bullet points
- 1 рекомендация

### Аналитическая записка (на 5-10 минут)

- Контекст + гипотезы
- 3-5 графиков с выводами
- Детальный анализ основного инсайта
- Рекомендации + риски

### Интерактивная презентация

- Данные в Plotly/Tableau
- Рассказываешь историю, переключая фильтры
- Аудитория может задать вопрос и покрутить данные

## Техника аннотаций

```python
# Прямо на графике
ax.annotate('Максимум: 85% конверсии',
            xy=(date, value), xytext=(date, value + 10),
            arrowprops=dict(arrowstyle='->'), fontsize=11)

# Текстовый блок
ax.text(0.02, 0.98, 'Конверсия упала после
редизайна формы (p < 0.01)',
        transform=ax.transAxes, verticalalignment='top',
        bbox=dict(boxstyle='round', facecolor='white', alpha=0.8))
```

## Частые ошибки

- **Информация без иерархии**: всё одинаково важно → ничто не важно
- **Данные без интерпретации**: «вот график» → а что с того?
- **Перегрузка деталями**: 15 метрик на одном слайде
- **Нет call to action**: вывод без рекомендации
