# Дизайн дашбордов

## 5-секундный тест

Открой дашборд. Закрой глаза на 5 секунд. Открой. Если за 5 секунд ты понял главный вывод — дашборд хорош.

## Структура дашборда

```
┌────────────────────────────────────────────┐
│  📊 Заголовок + период          [Фильтры] │
├──────────────────┬─────────────────────────┤
│                  │                         │
│  KPI 1  KPI 2   │    Главный график       │
│  KPI 3  KPI 4   │    (тренд, сравнение)   │
│                  │                         │
├──────────────────┴─────────────────────────┤
│                                             │
│   Детализация (таблицы, второстепенные)     │
│                                             │
└─────────────────────────────────────────────┘
```

### Принцип перевёрнутой пирамиды

1. **Сверху**: KPI — 4-6 ключевых метрик (крупно)
2. **В центре**: главный график — тренд, сравнение, основная история
3. **Снизу**: детали — таблицы, второстепенные разрезы

## KPI (Key Performance Indicators)

- **4-6 KPI**, не больше
- **Крупно** — число + контекст (изменение, цель, тренд)
- **Сравнение**: vs предыдущий период, vs план, vs прогноз

```
Доход: 12.5M ₽
↑ 8.3% vs прошлый месяц
● 94% от плана
```

## Фильтры и интерактивность

- **Фильтры** — сверху, влияют на весь дашборд
- **Дата** — всегда: день/неделя/месяц/период
- **Клик** по графику → фильтрация / drill-down
- **Не переусложняй**: 3-5 фильтров достаточно

## Типичные ошибки

### Слишком много на одном экране

> Если нужно скроллить — разрежь на несколько дашбордов.

### Метрики без контекста

❌ «Конверсия: 3.2%»
✅ «Конверсия: 3.2% (↑ 0.4 п.п. vs прошлый месяц, цель — 3.5%)»

### Неправильная агрегация

Среднее от средних ≠ правильное среднее. SUM в источнике ≠ SUM в BI. Разберись с вычислениями.

### Игнорирование аудитории

- **CEO**: 3-5 KPI, тренды, red/green индикаторы
- **Менеджер**: + детализация, drill-down до конкретных кейсов
- **Аналитик**: + raw data export, гибкие фильтры, SQL-доступ

### Слишком «красиво»

Data-ink ratio: убирай украшения. Градиенты, 3D, тени, анимация — отвлекают от данных.

## Практические правила

1. **Один дашборд — одна тема** (не смешивай маркетинг и финансы)
2. **Цвет только для смысла**: красный = проблема, зелёный = хорошо
3. **Сетка**: выравнивай элементы, используй модульную сетку
4. **Единый стиль**: одни единицы, один формат дат, одно форматирование чисел
5. **Mobile-last**: дашборды смотрят на больших экранах, не гонись за mobile
6. **Скорость**: если дашборд грузится > 5 секунд — агрегируй данные
