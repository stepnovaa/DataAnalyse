# Грамматика графики и теория визуализации

## Грамматика графики (Wilkinson, 1999)

Любой статистический график строится из независимых компонентов:

```
График = Данные + Геометрия + Эстетика + Статистика + Координаты + Фасеты + Тема
```

| Компонент | Что это | Пример |
|-----------|---------|--------|
| **Данные** | Что визуализируем | DataFrame |
| **Геометрия** | Как рисуем | `geom_point()`, `geom_bar()` |
| **Эстетика** | Связь данных и визуальных свойств | `aes(x=price, y=sales, color=category)` |
| **Статистика** | Преобразование данных | `stat_smooth()`, `stat_bin()` |
| **Координаты** | Система координат | Cartesian, Polar, Map |
| **Фасеты** | Разбиение на подграфики | `facet_wrap(~ category)` |
| **Тема** | Визуальное оформление | `theme_minimal()`, шрифты, цвета |

Эта грамматика реализована в:
- **ggplot2** (R) — оригинальная имплементация
- **Plotnine** (Python) — порт ggplot2
- **Plotly Express** — вдохновлён грамматикой, но с интерактивностью

## Принципы визуализации (Tufte)

Эдвард Тафт — гуру информационного дизайна:

### Data-Ink Ratio

> Data-Ink Ratio = чернила на данные / общие чернила

Максимизируй data-ink, убирай **chartjunk**:
- Сетки, тяжёлые рамки, 3D-эффекты, градиенты
- Каждый лишний пиксель отвлекает от данных

### Lie Factor

> Lie Factor = размер эффекта на графике / размер эффекта в данных

Должен быть = 1. Манипуляция масштабом — ложь.

### Small Multiples

Вместо одного сложного графика — серия простых, одинаковых по структуре. Так глаз сравнивает паттерны.

## Визуальное восприятие (Cleveland & McGill)

Точность восприятия количественных различий (от самой точной к неточной):

1. Позиция на общей шкале (dot plot)
2. Позиция на невыровненных шкалах (множественные bar charts)
3. Длина (bar chart)
4. Угол / наклон (pie chart)
5. Площадь (bubble chart)
6. Объём (3D)
7. Цвет (heatmap)

> Поэтому **bar chart > pie chart**, а **dot plot > bar chart**.

## Типы графиков по задаче

| Задача | Лучший выбор |
|--------|-------------|
| Сравнение величин | Bar chart (горизонтальный!) |
| Тренд во времени | Line chart |
| Распределение | Histogram, boxplot, violin |
| Корреляция | Scatter plot |
| Часть от целого | Stacked bar (не pie!) |
| Геоданные | Карта (choropleth / scatter map) |
| Множество сравнений | Small multiples |
