# Статистический вывод (Inferential Statistics)

## Что это

Инференциальная статистика позволяет делать выводы о **генеральной совокупности** (популяции) на основе **выборки**. Ты не можешь опросить всех пользователей — ты опрашиваешь 1000 и делаешь вывод обо всех.

## Ключевые понятия

### Популяция vs Выборка

| | Популяция (Population) | Выборка (Sample) |
|---|---|---|
| **Размер** | N (все) | n (часть) |
| **Параметры** | μ, σ (истинные, неизвестные) | x̄, s (оценки) |
| **Обозначение** | Греческие буквы | Латинские буквы |

### Оценка параметров

- **Точечная оценка**: одно число (x̄ = 42.3)
- **Интервальная оценка**: диапазон, в котором с заданной вероятностью лежит истинное значение

## Доверительный интервал (Confidence Interval)

**95% CI** означает: «Если бы мы повторили эксперимент 100 раз, в 95 случаях истинное значение попало бы в построенный интервал».

> ❌ Неправильно: «Вероятность что μ в интервале = 95%»
> ✅ Правильно: «95% построенных таким способом интервалов содержат μ»

### Формула для среднего (σ известна)

```
x̄ ± z* × (σ / √n)
```

- z* = 1.96 для 95% CI (из нормального распределения)
- σ/√n = стандартная ошибка среднего

### Формула для среднего (σ неизвестна)

```
x̄ ± t* × (s / √n)
```

- t* — из t-распределения с df = n-1
- При n > 30 t ≈ z

### Что влияет на ширину CI

| Фактор | Шире CI | Уже CI |
|--------|---------|--------|
| Размер выборки | Маленькая n | Большая n |
| Вариабельность данных | Высокая s | Низкая s |
| Уровень доверия | 99% | 90% |

## p-value

**p-value** — вероятность получить наблюдаемый (или более экстремальный) результат при условии, что нулевая гипотеза верна.

- **p < 0.05**: «Результат статистически значим на уровне 5%»
- **p-value НЕ равно** вероятности что нулевая гипотеза верна
- **p-value НЕ измеряет** размер эффекта
- **p-value НЕ говорит** о практической значимости

> При n = 1 000 000 даже микроскопический эффект будет «значимым». Всегда смотри на размер эффекта и доверительный интервал.

## Мощность теста (Statistical Power)

Мощность = P(отвергнуть H₀ | H₀ ложна) = 1 - β

- Зависит от: размера эффекта, n, α, вариабельности
- Типичная цель: мощность ≥ 80%
- Низкая мощность → не можешь обнаружить реальный эффект

## Ошибки

| | H₀ верна | H₀ ложна |
|---|---|---|
| **Отвергаем H₀** | Ошибка I рода (α) | ✓ Правильно (1-β) |
| **Не отвергаем H₀** | ✓ Правильно (1-α) | Ошибка II рода (β) |
