# Корреляция и регрессия

## Корреляция

Корреляция измеряет **силу и направление** линейной связи между двумя переменными.

### Коэффициент Пирсона (r)

- От -1 до +1
- 0 = нет линейной связи
- +1 = идеальная положительная (X↑ → Y↑)
- -1 = идеальная отрицательная (X↑ → Y↓)

```
r = 0.9          r = 0.0          r = -0.8
   ••••           • • ••            •••
  ••              • •  •               ••
 •                •• • •                 ••
•                  • •                    ••
```

### Интерпретация (Cohen)

| |r|| Сила |
|---|---|---|
| 0.1 — 0.3 | Слабая |
| 0.3 — 0.5 | Средняя |
| > 0.5 | Сильная |

### Ранговая корреляция Спирмена (ρ)

- Не требует линейности и нормальности
- Измеряет монотонную связь
- Работает с ординальными данными и выбросами
- Всегда используй рядом с Пирсоном — если они сильно расходятся, в данных есть нелинейность или выбросы

### Золотые правила

> **Корреляция ≠ причинность.** Продажи мороженого коррелируют с утоплениями. Причина — жаркая погода (третья переменная, конфаундер).

- Всегда строй scatter plot перед расчётом корреляции
- Анскомб quartet: 4 датасета с одинаковыми mean, variance, correlation, regression — и абсолютно разной формой
- Проверяй корреляцию не только на всей выборке, но и в разрезах (парадокс Симпсона)

## Линейная регрессия

Модель: **Y = β₀ + β₁X + ε**

- **β₀** — intercept (значение Y при X = 0)
- **β₁** — slope (изменение Y при увеличении X на 1)
- **ε** — ошибка, которую модель не объясняет

### Метод наименьших квадратов (OLS)

Минимизирует Σ(Yᵢ - Ŷᵢ)² — сумму квадратов остатков.

### Как оценить модель

| Метрика | Что измеряет |
|---------|-------------|
| **R²** | Доля объяснённой дисперсии (0-1). 0.8 = модель объясняет 80% вариации |
| **Adjusted R²** | R² со штрафом за лишние переменные |
| **F-статистика** | Значима ли модель в целом |
| **p-value коэффициентов** | Значим ли каждый предиктор |
| **RMSE / MAE** | Средняя ошибка предсказания в единицах Y |

### Допущения OLS

1. **Линейность**: связь Y и X линейна
2. **Независимость**: остатки независимы (нет автокорреляции)
3. **Гомоскедастичность**: постоянная дисперсия остатков
4. **Нормальность остатков**: для корректных p-value и CI
5. **Нет мультиколлинеарности**: предикторы не должны быть сильно скоррелированы

> Если допущения нарушены — p-value врут. Проверяй остатки всегда.

## Множественная регрессия

Y = β₀ + β₁X₁ + β₂X₂ + ... + βₚXₚ + ε

- Интерпретация β₁: изменение Y при увеличении X₁ на 1, **при фиксированных остальных X**
- **Мультиколлинеарность**: если X₁ и X₂ сильно скоррелированы, коэффициенты становятся нестабильными

## Python

```python
import statsmodels.api as sm
X = sm.add_constant(df[['x1', 'x2']])
model = sm.OLS(df['y'], X).fit()
print(model.summary())  # R², p-values, CI
```
