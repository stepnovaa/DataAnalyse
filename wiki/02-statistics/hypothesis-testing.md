# Проверка гипотез

## Фреймворк

Проверка гипотезы — формальная процедура: мы предполагаем, что эффекта нет, и спрашиваем данные: «Вы достаточно удивительны, чтобы я передумал?»

### Шаги

1. Сформулировать H₀ (нулевая: эффекта нет) и H₁ (альтернативная: эффект есть)
2. Выбрать уровень значимости α (обычно 0.05)
3. Выбрать тест
4. Посчитать тестовую статистику и p-value
5. Сравнить p-value с α и сделать вывод

## Основные тесты

### Сравнение средних

| Тест | Когда |
|------|-------|
| **Одновыборочный t-тест** | Среднее выборки = известному значению? |
| **Двухвыборочный t-тест** | Средние двух групп равны? |
| **Парный t-тест** | Измерения до/после на одних объектах |
| **Welch t-тест** | Две группы с разными дисперсиями |

### Непараметрические (когда данные не нормальны)

| Тест | Аналог t-теста |
|------|----------------|
| **Mann-Whitney U** | Двухвыборочный t-тест |
| **Wilcoxon signed-rank** | Парный t-тест |
| **Kruskal-Wallis** | ANOVA (3+ групп) |

### Категориальные данные

| Тест | Для чего |
|------|----------|
| **χ² (хи-квадрат)** | Независимость двух категориальных переменных |
| **Fisher's exact** | Когда ожидаемые частоты < 5 |

### Множественное сравнение (ANOVA)

- **One-way ANOVA**: средние в 3+ группах равны?
- **Post-hoc тесты** (Tukey HSD, Bonferroni): какие именно группы различаются?

## Поправка на множественное тестирование

Если делаешь 20 тестов с α = 0.05, ожидаешь **1 ложноположительный результат** по чистой случайности.

### Решения
- **Bonferroni**: α / k — очень консервативно
- **Holm-Bonferroni**: чуть менее консервативно
- **Benjamini-Hochberg**: контроль FDR (False Discovery Rate) — для исследовательских задач

## Практические предостережения

1. **p-hacking**: подгонять анализ под получение p < 0.05 — путь к невоспроизводимости
2. **Большие выборки**: при n > 100k почти всё «значимо» — смотри effect size
3. **Практическая vs статистическая значимость**: повышение конверсии на 0.01% статистически значимо при n=10M, но бизнесу неинтересно
4. **HARKing**: Hypothesising After Results are Known — формулировать гипотезу после того как увидел данные

## Python

```python
from scipy import stats
stats.ttest_ind(group_a, group_b)           # двухвыборочный
stats.ttest_rel(before, after)              # парный
stats.mannwhitneyu(a, b)                    # Манна-Уитни
stats.f_oneway(g1, g2, g3)                  # ANOVA
stats.chi2_contingency(contingency_table)   # хи-квадрат
```
