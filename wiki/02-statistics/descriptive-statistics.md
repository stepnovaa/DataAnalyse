# Описательная статистика

## Что это

Описательная (дескриптивная) статистика — это **сжатие данных до нескольких чисел**, которые описывают их ключевые свойства. Первый шаг любого анализа после загрузки данных.

## Меры центральной тенденции

| Мера | Формула / Суть | Когда использовать |
|------|---------------|-------------------|
| **Среднее (mean)** | Σx / n | Симметричное распределение без выбросов |
| **Медиана (median)** | 50-й перцентиль | Скошенное распределение, есть выбросы |
| **Мода (mode)** | Самое частое значение | Категориальные данные |

> **Золотое правило**: если среднее и медиана сильно расходятся — у тебя скошенное распределение и/или выбросы. Доверяй медиане.

## Меры разброса

| Мера | Что показывает |
|------|----------------|
| **Размах (range)** | max - min. Чувствителен к выбросам, почти бесполезен |
| **Дисперсия (variance)** | Средний квадрат отклонений от среднего. В квадратных единицах |
| **Стандартное отклонение (std)** | √дисперсии. В тех же единицах, что и данные. Основа основ |
| **IQR (межквартильный размах)** | Q3 - Q1. Устойчив к выбросам. Основа boxplot |
| **MAD (Median Absolute Deviation)** | Медиана абсолютных отклонений от медианы. Самый робастный |

## Меры формы

- **Скос (skewness)**: асимметрия распределения
  - > 0: хвост справа (доходы — большинство мало, единицы много)
  - < 0: хвост слева (оценки — большинство высокие, единицы провалились)
- **Эксцесс (kurtosis)**: «островершинность» относительно нормального распределения
  - > 0: больше выбросов, чем у нормального (тяжёлые хвосты — финансовые данные)

## Квартили, перцентили и boxplot

```
        Q1      Q2     Q3
        │       │      │
  ──────┬───────┬──────┬──────
  min   └─IQR──┘      └─ outliers
```

- **Q1** = 25-й перцентиль
- **Q2** = медиана = 50-й перцентиль
- **Q3** = 75-й перцентиль
- **IQR** = Q3 - Q1
- **Выбросы**: всё, что < Q1 - 1.5×IQR или > Q3 + 1.5×IQR

## Python

```python
import pandas as pd
df.describe()  # count, mean, std, min, 25%, 50%, 75%, max
df.skew()      # скос
df.kurtosis()  # эксцесс
df['col'].quantile([0.25, 0.5, 0.75])  # квартили
```

## Важно

Описательная статистика ничего не говорит о **причинах**. Она только описывает выборку. Для выводов о генеральной совокупности нужна [[inferential-statistics|инференциальная статистика]].
