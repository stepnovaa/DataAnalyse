# Распределения

## Что такое распределение

Распределение описывает, как часто встречаются разные значения случайной величины. В анализе данных понимание распределения критично для:
- Выбора правильного статистического теста
- Обнаружения аномалий
- Построения симуляций и прогнозов

## Основные распределения

### Нормальное (Гауссово)

```
         ╱‾‾‾╲
        ╱     ╲
       ╱       ╲
      ╱         ╲
  ───╯───────────╰───
    μ-3σ  μ   μ+3σ
```

- **Параметры**: μ (среднее), σ (стандартное отклонение)
- **68-95-99.7 правило**: 68% данных в μ±σ, 95% в μ±2σ, 99.7% в μ±3σ
- **Почему важно**: Центральная предельная теорема (см. ниже) — многие оценки стремятся к нормальному

### Биномиальное

- Моделирует **число успехов** в n независимых испытаниях с вероятностью p
- **Пример**: сколько из 100 пользователей кликнут по баннеру (p = 0.03)
- При больших n → приближается к нормальному

### Пуассона

- Моделирует **число событий** за фиксированный интервал времени
- **Параметр**: λ — средняя интенсивность
- **Примеры**: количество заказов в минуту, количество багов на 1000 строк кода
- **Свойство**: среднее = дисперсия = λ

### Экспоненциальное

- Моделирует **время между событиями** в пуассоновском процессе
- **Пример**: время между заказами, время до отвала пользователя
- Свойство «без памяти»: P(X > s + t | X > s) = P(X > t)

### Стьюдента (t-распределение)

- Похоже на нормальное, но с более тяжёлыми хвостами
- Используется в t-тестах, когда дисперсия неизвестна и оценивается по выборке
- При df → ∞ сходится к нормальному

### χ² (хи-квадрат)

- Сумма квадратов k независимых стандартных нормальных величин
- Используется в тестах на независимость категориальных переменных

## Центральная предельная теорема (ЦПТ)

> Распределение выборочного среднего стремится к нормальному при росте размера выборки, **независимо** от распределения исходных данных (при конечной дисперсии).

Это главная причина, почему нормальное распределение везде. Даже если данные не нормальны — средние по выборкам будут.

**Практическое правило**: n ≥ 30 обычно достаточно для применимости ЦПТ (но для скошенных данных может потребоваться больше).

## Как проверить нормальность

1. **Глазами**: гистограмма, Q-Q plot
2. **Тесты**: Shapiro-Wilk (n < 5000), Anderson-Darling, Kolmogorov-Smirnov
3. **Метрики**: skewness близок к 0, kurtosis близок к 3

> Не полагайся только на тесты — при больших выборках они отвергают нормальность даже при небольших отклонениях.
