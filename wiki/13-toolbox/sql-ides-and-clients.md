# SQL IDE и клиенты

## Критерии выбора

- Автодополнение (таблицы, колонки, JOIN'ы)
- Визуализация плана запроса
- Поддержка диалектов (PostgreSQL, MySQL, BigQuery, ...)
- Управление соединениями
- Экспорт данных

## Сравнение

| | DBeaver | DataGrip | pgAdmin | TablePlus | Beekeeper Studio |
|---|---|---|---|---|---|
| **Цена** | Бесплатно | $199/год | Бесплатно | $89 (разово) | Бесплатно / $99 |
| **БД** | 80+ | 20+ | Только PG | 10+ | 5+ |
| **ERD** | Да | Да | Нет | Нет | Нет |

| **План запроса** | Визуальный | Визуальный | Текстовый | Нет | Нет |

## DBeaver (бесплатный универсал)

- Поддерживает 80+ БД (включая NoSQL: MongoDB, Cassandra, Redis)
- ER-диаграммы
- Миграция данных (Export/Import мастер)
- Медленный на старте (Java)

**Для кого**: аналитик, которому нужен один инструмент для всего.

## DataGrip (от JetBrains)

- Лучшее автодополнение (понимает JOIN'ы, подсказывает колонки)
- Мощный рефакторинг (переименовать колонку → везде)
- Интеграция с git для SQL-файлов
- VCS для схемы БД

**Для кого**: разработчик, много пишущий SQL. Стоит своих денег.

## pgAdmin (только PostgreSQL)

- Официальный инструмент
- Бесплатный
- Веб-интерфейс (можно хостить на сервере)

## CLI-инструменты

```bash
# psql — родной клиент PostgreSQL
psql -h host -d database -c "SELECT ..."

# duckdb cli — аналитика на лету
duckdb sales.parquet -c "SELECT category, SUM(amount) FROM sales GROUP BY 1"

# usql — универсальный CLI (Postgres, MySQL, SQLite, ...)
usql pg://user:pass@host/db
```

## Рекомендация

- **Бесплатно + универсально**: DBeaver
- **Платно + лучшее UX**: DataGrip
- **Только Postgres**: pgAdmin
- **Быстро посмотреть данные**: DuckDB CLI или TablePlus
- **Дата-инженер**: DataGrip + psql + dbt CLI
