# ML vs Статистика

## Ложная дихотомия

ML и статистика — не враги. Это два взгляда на одну проблему: **извлечение знаний из данных**. Разница — в акцентах и целях.

## Сравнение

| | Статистика | Машинное обучение |
|---|---|---|
| **Цель** | Объяснить, проверить гипотезу | Предсказать, automated decision |
| **Фокус** | Интерпретация коэффициентов | Точность прогноза |
| **Данные** | Небольшие выборки, дизайн эксперимента | Огромные датасеты |
| **Модели** | Простые, интерпретируемые | Сложные, «чёрный ящик» |
| **Оценка** | p-value, CI, моделирование ошибок | Train/test, кросс-валидация |
| **Допущения** | Строгие (нормальность, линейность) | Минимальные |
| **Overfitting** | Редко (простые модели) | Главная проблема |
| **Культура** | Проверил гипотезу → опубликовал | Задеплоил → мониторишь |

## Когда статистика

- Нужно **понять причину**: «Почему продажи упали?» а не «Какие будут продажи?»
- **A/B-тест**: статистическая значимость, размер эффекта, CI
- **Научное исследование**: проверка гипотез
- **Регуляторные требования**: интерпретируемость обязательна (кредитный скоринг, медицина)

## Когда ML

- Нужно **предсказать**: «Какой пользователь отвалится?» а не «Почему пользователи отваливаются?»
- Много данных, много признаков
- Нелинейные сложные зависимости
- Автоматизация решений (recommendations, fraud detection)

## Где они пересекаются

- **Линейная регрессия**: статистическая модель, используемая в ML как baseline
- **Логистическая регрессия**: статистика (log-odds) + ML (классификация)
- **Байесовские методы**: Bayesian ML — оценка неопределённости в ML
- **Causal ML**: причинно-следственный вывод + ML (DoWhy, EconML)

## Практический компромисс

Хороший аналитик/data scientist использует оба подхода:

1. **EDA + статистика** для понимания данных и генерации гипотез
2. **ML** для построения предиктивной модели
3. **Статистические тесты** для валидации, что улучшение ML-модели не случайно
4. **Интерпретация** результатов через feature importance, SHAP

> «All models are wrong, but some are useful.» — George Box. И статистические, и ML.
