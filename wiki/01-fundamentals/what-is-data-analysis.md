# Что такое анализ данных

## Определение

**Анализ данных** — процесс извлечения значимой информации из сырых данных с целью принятия решений. Это не про инструменты и не про код — это про превращение шума в сигнал.

## Границы понятия

```
Сырые данные → Обработка → АНАЛИЗ → Интерпретация → Решение
                  ↑            ↑           ↑
            Data Engineering  ТЫ ЗДЕСЬ   Business
```

Анализ данных ≠ Data Science (шире, включает ML-моделирование)
Анализ данных ≠ BI (уже, BI — reporting и дашборды для бизнеса)
Анализ данных ∩ Статистика — пересекаются, но анализ шире (включает domain knowledge)

## Типы анализа по цели

| Тип | Вопрос | Пример |
|-----|--------|--------|
| **Дескриптивный** | Что произошло? | Сколько пользователей зарегистрировалось вчера? |
| **Диагностический** | Почему произошло? | Почему конверсия упала на 20% в среду? |
| **Предиктивный** | Что произойдёт? | Сколько пользователей отвалится в следующем месяце? |
| **Прескриптивный** | Что делать? | Каким пользователям отправить промокод, чтобы удержать? |

## Типы анализа по методу

- **Количественный** — числа, статистика, метрики
- **Качественный** — категории, тексты, отзывы (в т.ч. NLP)
- **Исследовательский** (EDA) — ищем закономерности без конкретной гипотезы
- **Подтверждающий** — проверяем конкретную гипотезу (A/B-тест)

## Ключевое

Анализ данных — это **не** про «сделай мне график». Это про:
1. Понять бизнес-вопрос
2. Найти/собрать нужные данные
3. Проверить их качество
4. Применить правильный метод
5. Интерпретировать результат в контексте бизнеса
6. Донести вывод до стейкхолдеров

Самая частая ошибка новичка: начать считать, не поняв вопрос.
