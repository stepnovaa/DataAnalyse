# Жизненный цикл данных

## Обзор

Жизненный цикл данных (Data Lifecycle) — это путь, который проходят данные от момента создания до удаления. Понимание цикла помогает строить надёжные системы и не терять данные.

## Этапы

```
┌──────────┐   ┌──────────┐   ┌──────────┐   ┌──────────┐   ┌──────────┐
│   СБОР   │ → │ ХРАНЕНИЕ │ → │ОБРАБОТКА │ → │  АНАЛИЗ  │ → │АРХИВ/УТИЛЬ
└──────────┘   └──────────┘   └──────────┘   └──────────┘   └──────────┘
                    ↕               ↕
              УПРАВЛЕНИЕ      КАЧЕСТВО
              (Governance)    (Quality)
```

### 1. Сбор (Collection / Ingestion)

- **Источники**: пользовательские события, логи, API, датчики, транзакции, внешние данные
- **Методы**: batch (пакетами), streaming (потоком), CDC (Change Data Capture)
- **Ключевой вопрос**: какие данные нам **реально** нужны, а не «давайте собирать всё»

### 2. Хранение (Storage)

- Выбор хранилища: реляционная БД, Data Lake, Data Warehouse, Object Storage
- Форматы: CSV (для обмена), Parquet (для аналитики), Avro (для стриминга), JSON (для API)
- Связано: [[../10-big-data/data-lake-architecture|Data Lake]], [[../11-data-engineering/data-warehouse-architecture|Data Warehouse]]

### 3. Обработка (Processing)

- **Очистка**: пропуски (см. [[../07-exploratory-analysis/missing-data-strategies|Стратегии для пропусков]])
- **Трансформация**: агрегации, join'ы, enrichment
- **Валидация**: проверка схемы, бизнес-правил
- Инструменты: Pandas/Polars (небольшие объёмы), Spark (большие), dbt (трансформации в DWH)

### 4. Анализ (Analysis)

- Разведочный анализ ([[../07-exploratory-analysis/eda-framework|EDA]])
- Статистический анализ ([[../02-statistics/moc-statistics|Статистика]])
- Машинное обучение ([[../09-machine-learning/moc-machine-learning|ML]])
- Визуализация результатов ([[../08-visualization/moc-visualization|Визуализация]])

### 5. Архивация и утилизация

- Данные, к которым не обращаются > N дней → холодное хранилище (дешевле)
- Устаревшие/ненужные данные → удаление
- Compliance: GDPR требует удаления персональных данных по запросу

## Принципы здорового жизненного цикла

1. **Каждый этап должен быть воспроизводим** — никаких ручных правок в продакшене
2. **Данные должны быть наблюдаемы** — ты знаешь, где они, какого качества, когда обновлялись
3. **Удаление — не враг** — не храни то, что не нужно; хранение стоит денег и создаёт риски
