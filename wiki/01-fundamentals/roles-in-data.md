# Роли в данных

## Кто есть кто

Индустрия данных страдает от размытых названий должностей. Вот карта — кто чем реально занят.

```
                    Бизнес-ценность →
    ┌──────────────┬──────────────────┬──────────────────┐
    │  Аналитик    │  Data Scientist  │  ML Engineer      │
    │  (Analyst)   │                  │                   │
    ├──────────────┼──────────────────┼──────────────────┤
    │ SQL, BI,     │ Статистика,      │ Продакшн-ML,      │
    │ дашборды,    │ эксперименты,    │ MLOps,            │
    │ отчёты       │ A/B-тесты,       │ пайплайны,        │
    │              │ предиктивные м.  │ мониторинг        │
    └──────────────┴──────────────────┴──────────────────┘
    ┌─────────────────────────────────────────────────────┐
    │              Data Engineer                          │
    │  ETL/ELT, хранилища, оркестрация, качество данных   │
    └─────────────────────────────────────────────────────┘
    ┌─────────────────────────────────────────────────────┐
    │              Analytics Engineer                     │
    │  Мост между инженерией и аналитикой: dbt,          │
    │  data modelling, self-serve аналитика               │
    └─────────────────────────────────────────────────────┘
```

## Детально

### Data Analyst (Аналитик данных)

**Главный инструмент**: SQL. **Результат**: ответ на бизнес-вопрос.
- Пишет запросы к БД и хранилищам
- Строит дашборды (Tableau, Power BI, Superset)
- Проводит ad-hoc анализ по запросу бизнеса
- Проверяет гипотезы через A/B-тесты
- Коммуницирует выводы стейкхолдерам

### Data Scientist

**Главный инструмент**: Python + статистика. **Результат**: модель/прогноз.
- Строит предиктивные модели (отток, LTV, рекомендации)
- Проектирует и анализирует эксперименты
- Работает с неструктурированными данными (NLP, изображения)
- Исследует данные глубже аналитика — ищет скрытые закономерности

### Data Engineer

**Главный инструмент**: Python + SQL + инфраструктура. **Результат**: надёжные пайплайны.
- Строит и поддерживает ETL/ELT-пайплайны
- Управляет хранилищами и Data Lake
- Обеспечивает качество, свежесть и доступность данных
- Оптимизирует запросы и хранение

### Analytics Engineer

**Главный инструмент**: dbt + SQL. **Результат**: чистые, задокументированные дата-модели.
- Трансформирует сырые данные в аналитические модели
- Пишет тесты и документацию для данных
- Строит self-serve слой для аналитиков (они сами берут готовые модели)

### ML Engineer

**Главный инструмент**: Python + MLOps. **Результат**: ML в продакшене.
- Разворачивает модели в production
- Строит ML-пайплайны и мониторинг
- Оптимизирует инференс (latency, стоимость)

## Реальность

В небольших компаниях один человек может совмещать 2-3 роли. Но важно понимать границы: «дата-сайентист, который чинит пайплайны» — это фактически ML Engineer, а не scientist.
