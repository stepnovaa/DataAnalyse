# Типы и структуры данных

## Уровни структурированности

| Тип | Описание | Примеры | Хранение |
|-----|----------|---------|----------|
| **Структурированные** | Строгая схема, строки и колонки | Таблицы SQL, CSV | Реляционные БД |
| **Полуструктурированные** | Самодокументированные, гибкая схема | JSON, XML, YAML, Parquet | NoSQL, Data Lake |
| **Неструктурированные** | Нет предопределённой модели | Текст, изображения, аудио, видео | Файловые системы, Object Storage |

## Типы данных (на уровне переменной)

### Числовые
- **Дискретные** — конечное число значений (количество заказов)
- **Непрерывные** — любое значение в диапазоне (температура, цена)

### Категориальные
- **Номинальные** — без порядка (страна, цвет, имя пользователя)
- **Ординальные** — с порядком, без фиксированного расстояния (оценка 1-5, уровень: junior/middle/senior)

### Специальные
- **Дата/время** — timestamp, интервалы, периоды
- **Булевы** — истина/ложь
- **Текстовые** — строки произвольной длины
- **Геопространственные** — координаты, полигоны (PostGIS)

## Шкалы измерений (Стивенс, 1946)

| Шкала | Свойства | Допустимые операции | Пример |
|-------|----------|---------------------|--------|
| **Номинальная** | Категории, = ≠ | Счёт, мода | ID пользователя |
| **Ординальная** | Категории + порядок | + медиана | Рейтинг 1-5 звёзд |
| **Интервальная** | Равные интервалы, нет истинного нуля | + среднее, разность | Температура в °C |
| **Абсолютная** | Истинный ноль, все операции | + умножение, отношение | Доход в рублях |

Шкала определяет, какие статистические методы **имеют смысл**. Средняя температура 20°C не означает «в два раза теплее, чем 10°C» (интервальная шкала — нет истинного нуля).

## Практическое правило

При загрузке нового датасета первым делом:
1. Определи тип каждой колонки
2. Проверь, соответствует ли тип реальным данным (int там, где категория — red flag)
3. Реши, нужна ли трансформация (нормализация, one-hot encoding)

См. [[../06-data-processing/data-cleaning|Очистка данных]] и [[../07-exploratory-analysis/univariate-analysis|Одномерный анализ]].
