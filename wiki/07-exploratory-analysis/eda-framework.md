# EDA-фреймворк

## Что такое EDA

**Exploratory Data Analysis** — подход, предложенный Джоном Тьюки (1977): исследуй данные без предварительных гипотез, дай им «рассказать историю». EDA — это диалог с данными, а не допрос.

## Фреймворк: 4 шага

```
Вопрос → Визуализация → Статистика → Вывод (и новый вопрос)
   ↑                                        │
   └────────────────────────────────────────┘
```

### Шаг 1: Пойми структуру

```python
df.shape          # сколько строк и колонок
df.info()         # типы данных, null-ы, память
df.head(10)       # первые строки
df.describe()     # статистики числовых колонок
df.describe(include='object')  # категориальные
```

Вопросы:
- Сколько данных? Достаточно для анализа?
- Какие типы колонок? Соответствуют ожидаемому?
- Есть ли явные проблемы (отрицательный возраст, дата в будущем)?

### Шаг 2: Найди проблемы

```python
df.isnull().sum()           # пропуски
df.duplicated().sum()        # дубликаты
df.nunique()                 # кардинальность
df.select_dtypes('object').apply(lambda x: x.str.strip().value_counts())
```

Приоритет: критические колонки (target, ключи, ключевые фичи).

### Шаг 3: Исследуй распределения и связи

Одномерный → Двумерный → Многомерный анализ.

См. [[../07-exploratory-analysis/univariate-analysis|Одномерный]], [[../07-exploratory-analysis/bivariate-analysis|Двумерный]], [[../07-exploratory-analysis/multivariate-analysis|Многомерный]].

### Шаг 4: Сформулируй выводы и гипотезы

После EDA ты должен ответить:
- Какие колонки самые важные?
- Какие закономерности видны?
- Что удивило (чего не ожидал)?
- Какие гипотезы будем проверять дальше?

## EDA-отчёт (шаблон)

```markdown
# EDA: [Название датасета]

## 1. Общая информация
- Строк: 100,000, колонок: 15
- Пропусков: 3.2% в колонке age
- Дубликатов: 0

## 2. Ключевые находки
- [Находка 1]
- [Находка 2]

## 3. Визуализации
- [График 1]
- [График 2]

## 4. Следующие шаги
- Проверить гипотезу X через A/B-тест
- Построить модель для Y
```

## Инструменты EDA одним кликом

- **pandas-profiling** (ydata-profiling): `ProfileReport(df)`
- **Sweetviz**: `analyze(df)`
- **AutoViz**: `AutoViz_Class()`
- **D-Tale**: интерактивная веб-панель

> Авто-EDA — стартовая точка, но не замена ручному анализу. Машина не задаёт вопросы — она только генерирует отчёты.
