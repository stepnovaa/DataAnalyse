# LLM в аналитике

## Что меняют LLM

LLM (ChatGPT, Claude, Gemini) меняют работу аналитика не «заменой», а **амплификацией**: быстрее писать запросы, искать инсайты, объяснять результаты.

## Text-to-SQL

Самое очевидное применение: описываешь вопрос на русском → получаешь SQL.

```
Вопрос: «Сколько активных пользователей из России сделали заказ за последнюю неделю?»
SQL:
SELECT COUNT(DISTINCT u.id) AS active_users
FROM users u
INNER JOIN orders o ON u.id = o.user_id
WHERE u.country = 'RU'
  AND u.status = 'active'
  AND o.created_at >= CURRENT_DATE - INTERVAL '7 days';
```

### Инструменты

- **OpenAI Codex / GPT-4**: общие модели, хороши для SQL
- **Vanna.ai**: специализированный text-to-sql фреймворк
- **GitHub Copilot**: автодополнение SQL в IDE (Datagrip, VSCode)
- **Claude**: хорош для сложных аналитических запросов

### Практика

1. Пишешь промпт с контекстом (схема таблиц, диалект SQL)
2. LLM генерирует запрос
3. **Ты проверяешь** — запускаешь на тестовых данных
4. Исправляешь edge cases

> LLM ускоряет написание SQL, но **не отменяет необходимость знать SQL**. Ты должен понять и проверить результат.

## Автоматический EDA

```python
# PandasAI — задаёшь вопрос о данных на естественном языке
from pandasai import SmartDataframe
sdf = SmartDataframe(df, config={'llm': llm})
sdf.chat('Какая категория приносит больше всего выручки?')
```

Инструменты: **PandasAI**, **LangChain DataFrame Agent**, **ChatGPT Code Interpreter**.

## Объяснение результатов

```
Промпт: «Вот результат регрессии. Объясни его бизнес-языком:
R²=0.78, коэффициент при цене = -2.3 (p<0.001), при возрасте = 0.05 (p=0.3)»
```

LLM переводит «stats talk» в «business talk».

## Ограничения и риски

| Риск | Пример |
|------|--------|
| **Галлюцинации** | LLM придумывает несуществующую колонку |
| **Конфиденциальность** | Не отправляй реальные данные в ChatGPT |
| **Контекстное окно** | LLM не знает твою схему из 50 таблиц |
| **Сложная логика** | Многоуровневые CTE, window functions с RANGE |

## Как использовать LLM безопасно

1. **Локальные модели** (Llama, Mistral через Ollama) — данные не покидают твой компьютер
2. **API с BAA** (Business Associate Agreement) — для regulated данных
3. **Только метаданные**: отправляй схему и вопрос, но не данные
4. **Всегда проверяй**: LLM — помощник, не замена мозгам
