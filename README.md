**Структурированная база знаний по анализу данных и базам данных.**  
109 страниц, 14 разделов, от фундамента до практических кейсов.

## Быстрый старт

Открой [`wiki/00-moc-data-analysis.md`](wiki/00-moc-data-analysis.md) — главная карта контента, навигационный хаб всей вики.

## Особенности

- **MOC-страницы** — каждый раздел открывается картой контента с описанием всех страниц
- **Cross-links** — перекрёстные ссылки между разделами, нелинейная навигация
- **Код** — SQL, Python, bash, конфиги — везде где уместно
- **Актуальность** — DuckDB, Polars, dbt, Data Mesh, pgvector, LLM-аналитика
- **Стиль** — структурированно, лаконично, таблицы сравнений, схемы, чек-листы
